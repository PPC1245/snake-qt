# 基于 Qt 的图形界面贪吃蛇（局域网联机版）

面向对象开发综合实训课程设计项目。在经典贪吃蛇玩法基础上实现了单机多人、局域网 2-4 人联机、多道具、音效与存档设置等功能，业务逻辑层与 GUI 视图层分层解耦。

## 功能特性

- 经典贪吃蛇玩法：移动、进食增长、边界/自身碰撞判定、游戏结束
- 7 类食物道具：普通、高分、加速、减速、反向等，按权重随机生成
- 单人模式 + 单机 2-4 人同屏对战（WASD / YGHJ / 8426 / 方向键 四组键位）
- 局域网 2-4 人联机对战（TCP 协议，端口 12345，服务器自动分配 P1-P4）
- 自定义蛇名（名字跟随蛇头移动）、实时 FPS 与网络延迟显示
- 背景音乐（Music.wav）+ 吃豆音效（eat.wav），音量可调
- 最高分 / 名字 / 音量 / 帧率显示等设置持久化（QSettings）
- 60 帧插值平滑动画，60×40 大地图
- 22 项自动化单元测试（test_core.cpp，全部通过）

## 开发环境

- 操作系统：Windows
- Qt 6.6.2（MinGW 64-bit）
- 编译器：MinGW 11.2.0（g++，C++17）
- 构建工具：qmake + mingw32-make

## 编译运行

1. 打开 Qt 命令行（Qt 6.6.2 (MinGW 64-bit)）或确保 Qt 的 bin 目录已加入 PATH
2. 在项目目录执行：

```bash
qmake snake.pro
mingw32-make
```

3. 运行 `release\snake.exe`

## 目录结构

```
snake/
├── main.cpp            # 程序入口：创建主窗口、初始化设置
├── snakewindows.cpp/h  # GUI 视图层：绘制、输入、界面控件
├── snakewindows.ui     # 界面布局定义
├── gamecore.cpp/h      # 业务核心：规则运算、状态管理、道具逻辑
├── netserver.cpp/h     # 局域网服务器（主机）
├── netclient.cpp/h     # 局域网客户端
├── netprotocol.h       # 网络消息协议定义
├── src.qrc             # 资源文件（音效、图标、背景）
├── test_core.cpp       # 22 项自动化单元测试
└── 素材：Music.wav / eat.wav / bg.png / bmp.png
```

## 操作说明

- 单人/多人模式在主菜单选择
- 联机模式：主机"创建房间"后等待加入；其他玩家输入主机 IP 加入
- 空格：暂停 / 继续；Esc：返回菜单
